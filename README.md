# Portfolio — Chiara Luongo

Sito statico (HTML/CSS/JS, nessuna build) pubblicato con GitHub Pages.

- **Aggiungere o modificare un progetto:** apri `content.js` e copia un blocco dentro `PROJECTS`. Le immagini vanno in `assets/projects/`.
- **Testi About e contatti:** sempre in `content.js`, dentro `PROFILE`.
- **Provarlo in locale:** `python3 -m http.server 8090` e apri http://localhost:8090
- **Pubblicare le modifiche:** `git add -A && git commit -m "..." && git push`
